# SubscribeSol Merchant Mobile

A powerful mobile management suite for merchants using the **SubscribeSol** protocol on the Solana blockchain.

## 🚀 Overview
SubscribeSol Merchant Mobile brings the full power of subscription management to Android devices. Merchants can securely connect their wallets, monitor real-time revenue, and update their subscription offerings on-the-go.

## ✨ Key Features
- **Secure Wallet Integration**: Powered by Solana Mobile Wallet Adapter (MWA).
- **Merchant Onboarding**: Seamless on-chain registration using unique merchant slugs.
- **Dynamic Plan Management**: Real-time updates for Daily, Weekly, Monthly, and Yearly subscription tiers.
- **Revenue Tracking**: Monitor SOL, USDC, and HAHICO balances directly from the dashboard.
- **On-Chain Updates**: Modify protocol settings, toggle HAHICO discounts, and manage plan availability with one-tap signing.

## 🛠 Tech Stack
- **Framework**: React Native / Expo (SDK 52)
- **Blockchain**: Solana Web3.js / @solana-mobile/mobile-wallet-adapter
- **Language**: TypeScript
- **Styling**: Expo Linear Gradient / Custom Dark Theme

## 📦 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/YOUR_USERNAME/subscribesol-merchant-mobile.git
   cd subscribesol-merchant-mobile
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run on Android device**
   ```bash
   npx expo run:android
   ```
